# AGENTS.md

All coding agents working in this repository (Claude Code, Cursor, Codex, Copilot or others) must follow **[CLAUDE.md](CLAUDE.md)** — the single operating contract for this project.

Minimum for every task:
1. Read `CLAUDE.md`, `PROGRESS.md`, `docs/LEARNINGS.md`, and the relevant sections of `IMPLEMENTATION_PLAN.md`. Inspect the actual repository state.
2. Follow the source-priority, architecture, retrieval-ladder, security and correctness rules (CLAUDE.md §1–§8). Preserve existing user changes.
3. Before finishing: run the checks actually available, update the task ledger in `PROGRESS.md` (CLAUDE.md §12), record learnings in `docs/LEARNINGS.md` and decisions in `docs/decisions/`, and reply in the CLAUDE.md §13 format.

Use only these tracking files: `PROGRESS.md`, `docs/LEARNINGS.md`, `docs/decisions/`.
